# Static frontend (Service Auto)

Multi-page **HTML5**, **CSS3**, **JavaScript**, and **Bootstrap 5** prototype for the auto shop site (assignment 1). Auth is simulated with `localStorage`; there is no API behind these pages.

**Run locally:** from this directory, `python3 -m http.server 8000`, then open http://localhost:8000.

For the full repository overview and the ASP.NET Core backend, see the **[root README](../README.md)**.
